# pi-secure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep credentials out of everything an LLM endpoint can observe (provider requests, session JSONL, transcript, exports) while the model still uses them through `{{sec:NAME}}` refs in shell commands and tool arguments.

**Architecture:** A pi extension with three pure modules (`vault`, `substitute`, `scrub`) holding all security logic, plus thin pi-glue modules that hook `input` / `tool_call` / `tool_result` / `context` / `before_provider_request`. Secrets reach processes through the child **environment** via a wrapped `bash` tool, so the literal value never enters the command string, the persisted transcript, or the model's context. Spec: `docs/superpowers/specs/2026-09-12-pi-secure-design.md`.

**Tech Stack:** TypeScript 5.9 (loaded uncompiled by pi via jiti), vitest 4.1, `@earendil-works/pi-coding-agent` 0.85.x (peer), `typebox` 1.3.7 (peer), Node ≥ 22.

**Spec:** `docs/superpowers/specs/2026-09-12-pi-secure-design.md` — read it alongside this plan. Section references below (§n) point into it.

## Global Constraints

- Node ≥ 22; dev machine verified on v24.20.0.
- pi packages are **peerDependencies at `*`** and devDependencies pinned to `0.85.1`. Never add a runtime npm dependency — a `pi install` uses `--omit=dev`, so runtime deps must be absent or truly necessary. There are none.
- Extension source is TypeScript loaded by jiti. No build step, no `dist/`.
- `{{sec:NAME}}` is the only model-facing syntax. `NAME` matches `/^[a-z][a-z0-9_-]{0,63}$/`.
- Values are **never** written to: session JSONL, custom entries, tool `details`, logs, temp files, or any file.
- No tool may reveal a value. There is no `sec_reveal`, and none is ever added (§6.2).
- Never interpolate `event.input` into an error string in a `tool_result` handler — it holds the **expanded** args with real values (§3 hazard).
- Every task ends with `npx vitest run` green and `npx tsc --noEmit` clean, then a commit.
- The canary-sweep invariant from Task 12 must stay green for the rest of the project: after any scenario, no session file or temp file contains a canary value.

- [ ] **Step 1: Write `src/refs.ts`**

```ts
import { createHash } from "node:crypto";

/** Shared by injection and scrubbing so both agree on what a ref looks like. */
export const REF_RE = /\{\{sec:([a-z][a-z0-9_-]{0,63})\}\}/g;
export const MAX_REF_BYTES = 1024 * 1024;
/** Guards against a 1-char value chewing up unrelated text. */
export const MIN_SCRUBABLE_LENGTH = 8;

export function isValidName(name: string): boolean {
  return /^[a-z][a-z0-9_-]{0,63}$/.test(name);
}

export function parseRef(text: string): string | undefined {
  const m = /^\{\{sec:([a-z][a-z0-9_-]{0,63})\}\}$/.exec(text);
  return m ? m[1] : undefined;
}

/** 4 hex chars. Derived only from the full value, never from a prefix. */
export function fingerprint(value: string): string {
  return createHash("sha256").update(value, "utf8").digest("hex").slice(0, 4);
}

/** Encodings a tool might echo back for the same underlying secret. */
export function derivedForms(value: string): string[] {
  const buf = Buffer.from(value, "utf8");
  return [value, buf.toString("base64"), buf.toString("base64url"), buf.toString("hex")];
}

/**
 * The shell variable a secret is exported as.
 *
 * `name` is public - the transcript shows `sec:gh_pat` - so this digest is a
 * collision suppressor, not a secret, and it must resist a *targeted* second
 * preimage: Task 6 derives names from text an untrusted endpoint can steer, and an
 * attacker who knows a victim's name and can land a second name in the vault wants
 * both to resolve to one variable, delivering the wrong credential to a chosen host.
 *
 * Two properties, in order of importance:
 *  - the sanitized body is NOT truncated, so names differing anywhere in their first
 *    64 chars (isValidName caps at 64) already differ here;
 *  - the tag is 64 bits of sha256 over the whole name. 32 bits was breakable: a
 *    40-char window plus an 8-hex tag makes "x"x45+"4a5" and "x"x45+"1y32" collide,
 *    which is a ~2^16 birthday walk. 64 bits makes the targeted search infeasible.
 *
 * Bound: 8 + up to 64 + 1 + 16 = 89 chars, always a valid POSIX identifier.
 */
export function envVarName(name: string): string {
  const sanitized = name.toUpperCase().replace(/[^A-Z0-9]/g, "_");
  const tag = createHash("sha256").update(name, "utf8").digest("hex").slice(0, 16);
  return `__PISEC_${sanitized}_${tag}`;
}

/**
 * Which already-held name, if any, would claim the same shell variable as `name`.
 * Extracted with an injectable resolver so the refusal path is testable: a genuine
 * 64-bit collision cannot be found in a test, and asserting "no collision" on
 * `a-b` vs `a_b` would not exercise the throw at all.
 */
export function findEnvVarCollision(
  existing: Iterable<string>,
  name: string,
  toVar: (n: string) => string = envVarName,
): string | undefined {
  const candidate = toVar(name);
  for (const other of existing) {
    if (other !== name && toVar(other) === candidate) return other;
  }
  return undefined;
}
```

```ts
import { MAX_REF_BYTES, envVarName, findEnvVarCollision, fingerprint, isValidName } from "./refs.ts";

export type SecretTier = "session" | "ambient";
export type SecretSource = "prompt" | "paste";

export interface VaultEntry {
  name: string;
  value: string;
  addedAt: number;
  tier: SecretTier;
  source: SecretSource;
  length: number;
  fingerprint: string;
}

/** Debug-safe projection: hasOwnProperty("value") must be false. */
export interface PublicEntry {
  name: string;
  length: number;
  fingerprint: string;
  addedAt: number;
  tier: SecretTier;
  source: SecretSource;
}

interface InternalEntry extends Omit<VaultEntry, keyof PublicEntry> {
  __piSecureSecret?: never;
}

function toPublic(entry: VaultEntry): PublicEntry {
  return {
    name: entry.name,
    length: entry.length,
    fingerprint: entry.fingerprint,
    addedAt: entry.addedAt,
    tier: entry.tier,
    source: entry.source,
  };
}

export class Vault {
  readonly #scopeKey: string;
  // `#map`, not `private map`: a TS `private` field is an ordinary own property at
  // runtime, so util.inspect(v, {customInspect:false}) and structuredClone(v) both
  // reach the values. A real private field is unreachable by either.
  #map = new Map<string, VaultEntry>();
  #toVar: (n: string) => string;

  // `toVar` is injectable so the collision guard's throw is testable: a genuine
  // 64-bit collision cannot be found in a test, and vi.mock cannot fake it either
  // because the default resolver binds to this module's own `envVarName`.
  constructor(scopeKey: string, toVar: (n: string) => string = envVarName) {
    this.#scopeKey = scopeKey;
    this.#toVar = toVar;
  }

  add(name: string, value: string, source: SecretSource): PublicEntry {
    if (!isValidName(name)) throw new Error(`invalid secret name: ${JSON.stringify(name)}`);
    // Two names must never share a shell variable, or a command asking for one
    // silently receives the other. Enforced at both name-entry points, add() and
    // rename(); expandBash can then assume distinctness.
    this.#assertNoCollision(name);

    if (!value || !value.trim()) throw new Error(`secret ${name} is empty`);
    if (Buffer.byteLength(value, "utf8") > MAX_REF_BYTES) {
      throw new Error(`secret ${name} is too large (>1MiB) — this looks like a file, not a token`);
    }
    const entry: VaultEntry = {
      name,
      value,
      addedAt: Date.now(),
      tier: "session",
      source,
      length: value.length,
      fingerprint: fingerprint(value),
    };
    this.#map.set(name, entry);
    // Projection, never the value-bearing entry: a failing toMatchObject on the
    // return would print the secret into CI output.
    return toPublic(entry);
  }

  get(name: string): VaultEntry | undefined {
    return this.#map.get(name);
  }
  has(name: string): boolean {
    return this.#map.has(name);
  }
  resolve(name: string): string | undefined {
    return this.#map.get(name)?.value;
  }
  remove(name: string): boolean {
    return this.#map.delete(name);
  }
  rename(oldName: string, newName: string): boolean {
    const entry = this.#map.get(oldName);
    if (!entry || !isValidName(newName) || this.#map.has(newName)) return false;
    // rename() is the SECOND place a name enters the vault; guarding only add()
    // would let `/sec rename` move a secret onto a colliding variable.
    this.#assertNoCollision(newName, oldName);
    this.#map.delete(oldName);
    this.#map.set(newName, { ...entry, name: newName });
    return true;
  }
  #assertNoCollision(name: string, ignore?: string): void {
    const clash = findEnvVarCollision(
      [...this.#map.keys()].filter((k) => k !== ignore),
      name,
      this.#toVar,
    );
    if (clash !== undefined) {
      throw new Error(`secret name ${name} collides with ${clash} in shell variable ${this.#toVar(name)}`);
    }
  }

  names(): string[] {
    return [...this.#map.keys()];
  }
  values(): string[] {
    return [...this.#map.values()].map((e) => e.value);
  }
  findByValue(value: string): VaultEntry | undefined {
    return [...this.#map.values()].find((e) => e.value === value);
  }
  entries(): PublicEntry[] {
    return [...this.#map.values()].map(toPublic);
  }
  size(): number {
    return this.#map.size;
  }
  clear(): number {
    const n = this.#map.size;
    this.#map.clear();
    return n;
  }
  scope(): string {
    return this.#scopeKey;
  }

  /** Inspectable only from inside the module: keeps `value` off enumerable props. */
  [Symbol.for("nodejs.util.inspect.custom")](): PublicEntry[] {
    return this.entries();
  }

  toJSON(): PublicEntry[] {
    return this.entries();
  }
}
```

```ts
export interface Ref {
  raw: string;
  name: string;
  start: number;
  end: number;
}

export type SecretResolver = (name: string) => string | undefined;

export function findRefs(text: string): Ref[] {
  const refs: Ref[] = [];
  REF_RE.lastIndex = 0;
  let m: RegExpExecArray | null;
  while ((m = REF_RE.exec(text))) {
    refs.push({ raw: m[0], name: m[1] as string, start: m.index, end: m.index + m[0].length });
  }
  return refs;
}

export function expandRefs(text: string, resolve: SecretResolver): { text: string; used: string[]; missing: string[] } {
  const used: string[] = [];
  const missing: string[] = [];
  const out = text.replace(REF_RE, (raw: string, name: string) => {
    const value = resolve(name);
    if (value === undefined) {
      if (!missing.includes(name)) missing.push(name);
      return raw;
    }
    if (!used.includes(name)) used.push(name);
    return value;
  });
  return { text: out, used, missing };
}

export function quoteForPosix(value: string): string {
  return `'${value.replace(/'/g, `'\\''`)}'`;
}
```

```ts
import { envVarName, findRefs, type Ref, type SecretResolver } from "../refs.ts";

export interface BashExpansion {
  command: string;
  env: Record<string, string>;
  used: string[];
  missing: string[];
}

type State = "code" | "sq" | "dq";

interface Interval {
  start: number;
  end: number;
}

/** Single-quoted and double-quoted spans. Escapes only matter inside double quotes. */
function quoteIntervals(text: string): { sq: Interval[]; dq: Interval[] } {
  const sq: Interval[] = [];
  const dq: Interval[] = [];
  let state: State = "code";
  let open = -1;
  for (let i = 0; i < text.length; i++) {
    const ch = text[i];
    if (state === "code") {
      if (ch === "'") {
        state = "sq";
        open = i + 1;
      } else if (ch === '"') {
        state = "dq";
        open = i + 1;
      } else if (ch === "\\" && i + 1 < text.length) {
        i++;
      }
    } else if (state === "sq") {
      if (ch === "'") {
        sq.push({ start: open, end: i });
        state = "code";
      }
    } else {
      if (ch === "\\") i++;
      else if (ch === '"') {
        dq.push({ start: open, end: i });
        state = "code";
      }
    }
  }
  return { sq, dq };
}

interface HeredocRegion {
  /** Body text between the operator line and the terminator. */
  start: number;
  end: number;
  /** A quoted delimiter ('EOF' / "EOF") suppresses parameter expansion. */
  inert: boolean;
}

/** Matches `<<EOF`, `<<-EOF`, `<<'EOF'`, `<<"EOF"`, `<<\EOF` at a line position. */
const HEREDOC_RE = /<<(-?)[ \t]*(\\?)(['"]?)([A-Za-z_][A-Za-z0-9_]*)\3/g;

export function heredocRegions(text: string): HeredocRegion[] {
  const { sq } = quoteIntervals(text);
  const regions: HeredocRegion[] = [];
  HEREDOC_RE.lastIndex = 0;
  let m: RegExpExecArray | null;
  while ((m = HEREDOC_RE.exec(text))) {
    // Discard an operator that a quote swallows (e.g. echo "<<EOF").
    if (sq.some((r) => m!.index >= r.start && m!.index < r.end)) continue;
    const delimiter = m[4] as string;
    const dash = Boolean(m[1]);
    const inert = Boolean(m[3]) || Boolean(m[2]);
    const lineEnd = text.indexOf("\n", m.index + m[0].length);
    if (lineEnd === -1) continue;
    let cursor = lineEnd + 1;
    let bodyStart = cursor;
    let bodyEnd = -1;
    let found = false;
    while (cursor <= text.length) {
      const nextBreak = text.indexOf("\n", cursor);
      const line = text.slice(cursor, nextBreak === -1 ? text.length : nextBreak);
      const terminator = dash ? line.replace(/^\t+/, "") : line;
      if (terminator === delimiter) {
        bodyEnd = cursor;
        found = true;
        break;
      }
      if (nextBreak === -1) break;
      cursor = nextBreak + 1;
    }
    if (!found) {
      // Unterminated heredoc on this line (common with `<<` in a for-loop);
      // treat the remainder as the body so we still never leak into argv.
      bodyEnd = text.length;
    }
    regions.push({ start: bodyStart, end: bodyEnd, inert });
  }
  return regions;
}

export function expandBash(command: string, resolve: SecretResolver): BashExpansion {
  const env: Record<string, string> = {};
  const used: string[] = [];
  const missing: string[] = [];

  const bind = (name: string): string | undefined => {
    const value = resolve(name);
    if (value === undefined) {
      if (!missing.includes(name)) missing.push(name);
      return undefined;
    }
    const varName = envVarName(name);
    env[varName] = value;
    if (!used.includes(name)) used.push(name);
    return varName;
  };

  const regions = heredocRegions(command);
  const inInertRegion = (index: number): boolean =>
    regions.some((r) => r.inert && index >= r.start && index < r.end);

  const { sq, dq } = quoteIntervals(command);
  const edits: Array<{ start: number; end: number; text: string }> = [];

  for (const ref of findRefs(command)) {
    // A quoted-delimiter heredoc body performs no expansion, so the ref cannot be
    // substituted here. Record it as unusable rather than silently dropping it:
    // the caller blocks on `missing` instead of running a command that would send
    // the literal placeholder.
    if (inInertRegion(ref.start)) {
      if (!missing.includes(ref.name)) missing.push(ref.name);
      continue;
    }
    const varName = bind(ref.name);
    if (varName === undefined) continue; // unknown name: leave the literal ref for the caller to report

    const inHeredoc = regions.some((r) => !r.inert && ref.start >= r.start && ref.end <= r.end);
    const inDq = dq.some((r) => ref.start >= r.start && ref.end <= r.end);
    const inSq = sq.some((r) => ref.start >= r.start && ref.end <= r.end);

    // Brace form everywhere except a single-quoted span. Braces matter: a ref
    // followed by a word character (`{{sec:x}}suffix`) would otherwise read the
    // variable as `VARsuffix`.
    const refText = inSq ? null : inHeredoc || inDq ? "${" + varName + "}" : `"${'$'}{${varName}}"`;

    if (inSq) {
      // The ONLY edit is at the ref itself: close the single quote, splice in the
      // double-quoted variable, reopen. Touching characters around the ref (an
      // earlier draft deleted `ref.start - 1`, the space before it) drops the
      // span's closing quote and yields an unterminated quote — a bash syntax
      // error, not a silent literal.
      //   'A {{sec:x}} B'  ->  'A '"${VAR}"' B'
      //   '{{sec:x}} B'    ->  ''"${VAR}"' B'      (leading empty quote is correct)
      //   'A {{sec:x}}'    ->  'A '"${VAR}"''       (trailing empty quote likewise)
      edits.push({ start: ref.start, end: ref.end, text: `'"${'$'}{${varName}}"'` });
      continue;
    }
    edits.push({ start: ref.start, end: ref.end, text: refText as string });
  }

  let out = command;
  for (const edit of [...edits].sort((a, b) => b.start - a.start)) {
    out = out.slice(0, edit.start) + edit.text + out.slice(edit.end);
  }
  return { command: out, env, used, missing };
}
```

- [ ] **Step 4b: Make the lexer comment-aware (controller ruling after the task review)**

`quoteIntervals` as drafted tracks only `'`, `"` and backslash escapes. Bash also has
comments, and an unlexed `#` lets two prose apostrophes on different lines pair into a
**phantom quote span that swallows a ref**. Confirmed at runtime, not theorized:

```
# don't
echo {{sec:gh_pat}} > /tmp/o  # it's
```

expands to `echo '"$__PISEC_GH_PAT_…"'`, so the target receives the **literal variable
name** while the result reports `used: ["gh_pat"]` and `missing: []` — the caller
believes the secret was delivered. A second repro put a `"` in a comment and produced a
bare unquoted `$VAR`, which word-split a value containing a space into three arguments
(and would glob-expand a `*`). Neither leaks the value, but both are silent wrong
credential delivery, and Task 7's guard consumes this same lexer.

Three requirements, each with a test that reproduces the case above:

1. **Comments — a `wordStart` flag, not a character lookup.** In code state, `#`
   begins a comment running to end of line when it starts a *word*. Reading the raw
   preceding character is **not** the bash rule and two counterexamples reproduce at
   head:

   ```
   (cd .)#don't
   echo {{sec:gh_pat}}
   (ls)#it's
   ```
   Bash treats both `#`s as comments (`(` and `)` are word starts), so the apostrophes
   are never seen. A preceding-character table that omits `(`/`)` instead pairs them
   into a phantom span around the ref and emits `echo '"$VAR"'` — silent non-delivery
   with `used: ["gh_pat"]`, `missing: []`. Likewise `echo a\;#"b' 'c …'`: `\<char>` is
   an escaped semicolon, so `#` is mid-word and **not** a comment; a raw-character test
   reads the `;` and wrongly comments.

   Maintain the flag in the lexer:
   - true at index 0, and after a newline, space, tab, or any of `( ) < > ; | &`;
   - cleared by every other character;
   - `\<char>` consumes the escape and the escaped character **without** setting
     `wordStart` and without quote tracking;
   - consulted only in code state, so `#` inside `'…'`, `"…"`, `$'…'`, `$"…"` is text.

   `echo a#b` stays one word.

   The set was **measured against `/bin/bash`**, because folklore is wrong in both
   directions — too narrow leaves the `;#` fail-open below, too wide swallows a ref
   that follows a real value:

   - `echo a;#c`, `echo hi|#b`, `echo a&#x` → comment (yes)
   - `x=#hello` → value is literally `#hello` (NO)
   - `echo x=$(echo 1)#c` → prints `1#c` (NO)
   - `echo a>#b` → **is** a comment after `>`: the redirect is left targetless, so bash aborts with a syntax error and no file is created (excluded from our set anyway — see the note below)
   - `echo a#b` → one word (NO)

   Regression the whitespace-only rule missed (silent wrong-credential delivery,
   `missing: []`):

   ```
   echo hi;#don't
   echo {{sec:gh_pat}} is here;#it's
   ```

   `>` is left out of the set even though bash comments there, because every
   `>#word` command is bash-rejected anyway, so our classification cannot change what
   the child receives. Keeping it out avoids teaching the lexer a sixth case for
   zero behavioral gain.

   Both apostrophes sit inside comments, so bash never pairs them; a whitespace-only
   rule pairs them into a phantom span, emits `echo '"$VAR"'`, and hands the program
   the literal variable name while reporting success.
2. **`$'…'` and `$"…"`.** Each is its own span, opened by `$'` / `$"` and closed by the
   next unescaped `'` / `"`, so a `"` inside `$"…"` does not open a double-quote interval
   and a `'` inside `$'…'` closes it and nothing else. The two forms are **not** the same
   to bash, so the emission differs — this is what earlier wording obscured:
   - `$"…"` behaves like `"…"`, so expansion works in place: `$"a{{sec:x}}b"` →
     `$"a${VAR}b"`.
   - `$'…'` performs **no** parameter expansion, so an in-place `$VAR` would reach the
     program as a literal. The ref must break out of the span the way a single-quoted ref
     does: `$'{{sec:x}}'` → `$''"$VAR"''`.
   Either way `missing` stays empty and the child receives the real value; prove it by
   running the command and matching its output, not by matching the rewritten string.
3. **Heredoc bodies are not quote context.** Bash performs no quote processing inside a
   heredoc body — every `'` and `"` there is literal — so quote tracking must skip **both
   kinds** of heredoc body (quoted and unquoted delimiters) and carry no quote state
   across them. Skipping only quoted bodies leaves a silent fail-open, confirmed at head:

   ```
   cat <<EOF
   don't
   EOF
   echo {{sec:gh_pat}} && echo 'x'
   ```

   An **even** number of body apostrophes opens *and closes* a fabricated span over the
   later ref, so the command parses, runs, and prints the literal `"$VAR"` while
   `missing` stays empty. That is the `;#` defect reborn through a different construct —
   and lone apostrophes in prose heredocs are ordinary, so the odd-count variant
   (over-blocking a command that would have worked) is common too.

6. **The heredoc skip must `continue`, not fall through.** `const ch = text[i]` is read
   before the skip, and the `break` inside `for (const body of heredocBodies)` exits only
   that inner loop — control then evaluates the **stale** `ch` (the body's first character)
   at the **post-jump** index. A body beginning with `'` therefore opens `state = "sq"` with
   `open = body.end - 1`, a span anchored in the wrong place. Measured at `7c17169`:
   `cat <<EOF / 'don't / EOF / echo {{sec:t}}` -> `missing: ["t"]` (over-block on a command
   bash runs), while the identical body starting with `d` is correct.

   Fix must restructure the lookup, because **a plain `continue` does not work**: the jump
   currently sits inside `for (const body of heredocBodies)`, so `continue` targets *that*
   loop — verified in a scratch copy, where `break` -> `continue` changed nothing and the
   test still failed. Both reviewers proposed exactly that one-word fix; only running it
   caught them. Use a `find` and continue the scan loop:

   ```ts
   const body = heredocBodies.find((b) => i >= b.start && i < b.end);
   if (body) {
     i = body.end - 1;      // loop increments past the last body char
     wordStart = true;      // body ends with a newline before the terminator line
     continue;              // req6: never re-process the stale `ch` at the new index
   }
   ```

   Leave a comment saying why, or the next reader "simplifies" it back into the inner loop.

7. **An escape pair must CLEAR `wordStart`.** `\<char>` is word text, so after it the next
   character is mid-word — but the escape branch leaves the flag untouched, so it inherits
   whatever the preceding boundary set. `echo $(printf a)\;#b'c {{sec:t}} d'`: `)` sets the
   flag true, the escape does not clear it, `#` is misread as a comment, the `'…'` span is
   never recorded, and the ref is emitted in code context as `"$VAR"` — which bash then
   reads as being **inside** those single quotes. Proved end-to-end by running what we emit:
   the child prints `a;#bc "$__PISEC_T_" d` while `missing: []` and `used: ["t"]` report
   success. `echo a\;#b'c … d'` (the case the current test uses) works, because the `a`
   happened to clear the flag — the test passes for the wrong reason. Same in the `\$`
   sub-branch. Fix: set `wordStart = false` when consuming an escape pair.

8. **`>` joins the boundary set.** It was excluded on the argument that any `>#word` command
   is a syntax error so classification cannot change delivery, and that argument survives
   measurement — `: >#f`, `echo hi >#log`, `: <#f`, `echo hi <#f`, `echo x <<<#f` all exit 2
   and create no file, so bash comments after `<`, `>` and `<<<` alike. The exclusion is
   therefore harmless, but an exception whose only justification is unreachability misleads
   the next reader (this file already shipped a wrong `>#log` comment once), and it makes
   the set asymmetric against `<`. Normalize to the measured rule.

5. **`heredocRegions` must not be heredoc-blind about its own inputs.** It decides whether
   a `<<` is a real operator or text swallowed by a quote by asking `quoteIntervals` — but
   the regions it is computing are not available yet, so this call originally passed none.
   A body's apostrophes could then fabricate a span that hides a **later** operator, whose
   body never gets excluded, reintroducing requirement 3's defect through a second door:

   ```
   cat <<'MSG'
   Don't do this
   MSG
   cat <<EOF
   It's fine
   EOF
   echo {{sec:gh_pat}} && echo 'x'
   ```

   Measured at the time: over-block (missing = the ref) without the trailing `echo 'x'`,
   and `echo '"$VAR"' && echo 'x'` with `missing: []` when it is appended — silent
   non-delivery reported as success. Every single-body test passed, which is why the
   rounds' fixtures missed it.

   Fix, measured in a scratch copy before adoption: hoist `const regions` above the scan
   and recompute `swallowed` **per operator** against `quoteIntervals(text, regions)`.
   Operators are examined left-to-right, so every region preceding the current operator is
   already known — the dependency is not circular after all. An operator genuinely inside
   a quote (`echo '<<EOF'`, whose command is a bash syntax error) must still block.

4. **Fail closed only on genuine uncertainty.** If quote tracking in *code context* ends
   with a quote still open, every ref at or after that opening goes into `missing`, so
   the caller blocks with a real explanation rather than running a command whose quoting
   we guessed. After requirement 3 this must not fire for heredoc bodies or any other
   construct where bash treats quotes as text: over-blocking a runnable command is also a
   defect, just a quieter one.

```ts
import { MIN_SCRUBABLE_LENGTH, derivedForms } from "./refs.ts";

export interface SecretProvider {
  values(): string[];
  findByValue(value: string): { name: string } | undefined;
}

export interface ScrubOptions {
  /** Shape masking. Default true. Disable for file-content reads to avoid corrupting write-back. */
  shapes?: boolean;
}

export interface ScrubResult {
  text: string;
  hits: number;
}

const GENERIC = "{{sec:redacted}}";

/** Anchored provider formats. Longest prefixes first so `dckr_pat_` wins over `pat_`. */
/**
 * Anchored provider formats, most specific prefix first so `dckr_pat_` wins over
 * `pat_`-like forms and `sk-ant-` wins over `sk-`.
 *
 * Built as an array of single-line sources joined with `|`, and NOT as a
 * multi-line String.raw template. A template literal here embeds real newlines and
 * indentation into the pattern, so `(?:\n  dckr_pat_…` would demand a newline before
 * every token and match nothing — a silent, total failure of shape scrubbing. There
 * is no `x` (verbose) flag in this V8 to make the readable form work:
 * `new RegExp(src, "gx")` throws SyntaxError at module load.
 */
const PREFIX_SOURCES = [
  "dckr_pat_[A-Za-z0-9_\\-]{20,}",
  "github_pat_[A-Za-z0-9_]{20,}",
  "gh[pousr]_[A-Za-z0-9]{20,}",
  "sk-ant-[A-Za-z0-9_\\-]{20,}",
  "sk-[A-Za-z0-9]{20,}",
  "AIza[0-9A-Za-z_\\-]{30,}",
  "(?:AKIA|ASIA)[0-9A-Z]{16}",
  "xox[baprs]-[A-Za-z0-9\\-]{10,}",
  "glpat-[A-Za-z0-9_\\-]{20,}",
  "npm_[A-Za-z0-9]{30,}",
  "pypi-Po-[A-Za-z0-9]{20,}",
  "hf_[A-Za-z0-9]{20,}",
];
const PREFIX_RE = `(?:${PREFIX_SOURCES.join("|")})`;

const PEM_RE = String.raw`-----BEGIN [A-Z0-9 ]*PRIVATE KEY-----[\s\S]*?-----END [A-Z0-9 ]*PRIVATE KEY-----`;
const JWT_RE = String.raw`eyJ[A-Za-z0-9_\-]{5,}\.eyJ[A-Za-z0-9_\-]{5,}\.[A-Za-z0-9_\-]{8,}`;
// `&` is deliberately ALLOWED in the value class. Excluding it produced partial
// masking: `aws_secret_access_key=wJal…EXAMPLEKEY&more` masked up to the `&` and
// leaked the rest of a real secret in the clear. Over-masking a URL-ish tail costs
// nothing; under-masking a password costs the whole design.
// The `(?!\{\{sec:)` before the capture is load-bearing, not decoration.
// `scrubText` runs the value pass FIRST, so by the time shapes see the text a known
// secret is already `{{sec:NAME}}`. Without the lookahead, KV_RE happily captures its
// own marker (`password={{sec:gh_pat}}` -> `password={{sec:redacted}}`), which destroys
// the name the model needs to reuse the ref, and makes scrubbing non-idempotent: any
// text scrubbed twice loses every name permanently. Verified by measurement: without it
// `password=<real gh token>` degrades on the second pass; with it the name survives and
// genuine KV-shaped secrets (`api_key = wJalrXUt…`) still mask to the generic marker.
const KV_RE = String.raw`[A-Za-z0-9_\-]*(?:token|secret|password|passwd|pwd|api[_-]?key|authorization|access[_-]?key|private[_-]?key)[A-Za-z0-9_\-]*["']?\s*[=:]\s*["']?(?!\{\{sec:)([^\s"'<>\\]{8,})`;

/**
 * Excluded wholesale. The git-SHA rule matters most: pi prints 40-hex commit
 * hashes constantly and masking them would break normal work.
 *
 * Matched ANCHORED against the whole candidate, never as an overlap search. An
 * unanchored deny test is a false negative in the dangerous direction: the Slack
 * token `xoxb-123456789012-…` contains the 7-hex run `6789012`, and an Anthropic
 * key with a long hex tail contains a 40-hex run, so either would have been left
 * fully visible to a logging endpoint. Only a candidate that IS entirely a
 * digest-shaped token is exempt.
 */
const DENY_SOURCES = [
  "[0-9a-f]{40}", // git SHA-1
  "[0-9a-f]{64}", // sha256 digest
  "[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}", // uuid
  "[0-9a-f]{7}", // short git SHA
];
const DENY_ANCHORED = new RegExp(`^(?:${DENY_SOURCES.join("|")})$`, "i");

const SHAPE_RE = new RegExp(`(?:${PEM_RE}|${JWT_RE}|${PREFIX_RE}|${KV_RE})`, "gi");

/** Whole-candidate exemption — see DENY_SOURCES for why this must not overlap-match. */
function isDenied(candidate: string): boolean {
  return DENY_ANCHORED.test(candidate);
}

export function shannonEntropy(s: string): number {
  if (!s.length) return 0;
  const freq = new Map<string, number>();
  for (const ch of s) freq.set(ch, (freq.get(ch) ?? 0) + 1);
  let h = 0;
  for (const n of freq.values()) {
    const p = n / s.length;
    h -= p * Math.log2(p);
  }
  return h;
}

export function looksCredentialish(text: string): boolean {
  const t = text.trim();
  if (t.length < 20) return false;
  if (DENY_ANCHORED.test(t)) return false; // same anchored exemption, no recompile per call
  if (/^https?:\/\//i.test(t) || /^[A-Za-z0-9._/-]+$/.test(t) && t.includes("/")) return false;
  const classes = [/[a-z]/, /[A-Z]/, /[0-9]/, /[^A-Za-z0-9\s]/].filter((r) => r.test(t)).length;
  return classes >= 2 && shannonEntropy(t) > 3.6;
}

/** Longest-first so a containing secret wins over a contained one. */
function byLengthDesc(a: string, b: string): number {
  return b.length - a.length;
}

export function maskValues(text: string, secrets: readonly string[]): ScrubResult {
  const forms: Array<{ form: string }> = [];
  for (const value of secrets) {
    if (value.length < MIN_SCRUBABLE_LENGTH) continue;
    for (const form of derivedForms(value)) forms.push({ form });
  }
  forms.sort((a, b) => byLengthDesc(a.form, b.form));
  let hits = 0;
  let out = text;
  for (const { form } of forms) {
    if (form.length < MIN_SCRUBABLE_LENGTH) continue;
    let cursor = out.indexOf(form);
    if (cursor === -1) continue;
    while (cursor !== -1) {
      out = out.slice(0, cursor) + GENERIC + out.slice(cursor + form.length);
      hits++;
      cursor = out.indexOf(form, cursor + GENERIC.length);
    }
  }
  return { text: out, hits };
}

export function maskShapes(text: string): ScrubResult {
  let hits = 0;
  const out = text.replace(SHAPE_RE, (match: string, ...rest: unknown[]) => {
    // When the KV alternative matched, the credential is a capture group.
    const captured = typeof rest[0] === "string" ? (rest[0] as string) : undefined;
    const target = captured ?? match;
    if (isDenied(target)) return match;
    if (target.length < MIN_SCRUBABLE_LENGTH) return match;
    hits++;
    return captured ? match.slice(0, match.length - captured.length) + GENERIC : GENERIC;
  });
  return { text: out, hits };
}

export function scrubText(text: string, vault: SecretProvider, opts: ScrubOptions = {}): ScrubResult {
  if (!text) return { text, hits: 0 };
  let out = text;
  let hits = 0;

  // Name-exact pass first: a vault value masks to its own ref so the model can reuse it.
  const entries = vault.values();
  for (const value of [...entries].sort(byLengthDesc)) {
    if (value.length < MIN_SCRUBABLE_LENGTH) continue;
    const name = vault.findByValue(value)?.name;
    const token = name ? `{{sec:${name}}}` : GENERIC;
    for (const form of derivedForms(value)) {
      let cursor = out.indexOf(form);
      while (cursor !== -1) {
        out = out.slice(0, cursor) + token + out.slice(cursor + form.length);
        hits++;
        cursor = out.indexOf(form, cursor + token.length);
      }
    }
  }

  if (opts.shapes !== false) {
    const shapes = maskShapes(out);
    if (shapes.hits) {
      out = shapes.text;
      hits += shapes.hits;
    }
  }
  return { text: out, hits };
}

export function scrubDeep<T>(value: T, vault: SecretProvider, opts?: ScrubOptions): { value: T; hits: number } {
  let hits = 0;
  const walk = (node: unknown): unknown => {
    if (typeof node === "string") {
      const r = scrubText(node, vault, opts);
      hits += r.hits;
      return r.text;
    }
    if (Array.isArray(node)) return node.map(walk);
    if (node && typeof node === "object") {
      const out: Record<string, unknown> = {};
      for (const [k, v] of Object.entries(node)) out[k] = walk(v);
      return out;
    }
    return node;
  };
  return { value: walk(value) as T, hits };
}
```

**Requirements found by attacking the shipped design. Both are confidentiality bugs on the capture
path, and both were confirmed by running the brief's own implementation:**

A. **Capture must not leave a tail behind.** The KV value class here excludes `&`, while Task 5's
   scrub class deliberately allows it. Measured: `findCandidates("password=Tr0ub4dor&xyzabcDEF")`
   yields the value `"Tr0ub4dor"` alone, so `applyCapture` rewrites the head to `{{sec:name}} and
   **leaves `&xyzabcDEF` in the submitted text**, which reaches the transcript and the request while
   the receipt announces success. Worse than a scrub-side miss: scrub masks the whole occurrence or
   none, whereas capture partially rewrites and reports protection. Fix in two parts — align the
   value class with Task 5's (allow `&` and backslash), and extend any KV candidate that stopped
   mid-token to the full whitespace-free token, so a match can never end inside a credential.
   Over-capture then becomes possible (`password=abc&&echo` is one token and would be captured
   whole, mangling a chained command); that is the accepted direction, because a mangled submission
   is visible to the user and reversible via the receipt and `/sec restore`, while a leaked tail is
   neither. Put that reasoning in the code comment.

B. **Capture every occurrence, not just the first.** The bare-entropy fallback uses
   `text.indexOf(token)`, which returns the first index for every split hit. Measured: a token
   appearing twice in one message produces one candidate at `start: 7`, and after capture the second
   copy is still in the text. The anchored and KV collectors use `/g` and already find every
   occurrence; give the entropy path the same behavior while keeping the reserved-ref and deny filters.

Tests to add: a KV value containing `&` captures the whole token with no tail left behind; a KV value
containing a backslash likewise; a bare high-entropy token appearing twice yields two candidates and

reintroduces a tail must delete an intentional assertion rather than a silent one.

```ts
import { findRefs } from "./substitute.ts";
import { isValidName } from "./refs.ts";
import { looksCredentialish, shannonEntropy } from "./scrub.ts";

export type Confidence = "anchored" | "kv" | "entropy";

export interface Candidate {
  value: string;
  start: number;
  end: number;
  confidence: Confidence;
  hint?: string;
}

const ANCHORED: Array<{ re: RegExp; hint: string }> = [
  { re: /dckr_pat_[A-Za-z0-9_\-]{20,}/g, hint: "docker_pat" },
  { re: /github_pat_[A-Za-z0-9_]{20,}/g, hint: "github_pat" },
  { re: /gh[pousr]_[A-Za-z0-9]{20,}/g, hint: "github" },
  { re: /sk-ant-[A-Za-z0-9_\-]{20,}/g, hint: "anthropic" },
  { re: /AIza[0-9A-Za-z_\-]{30,}/g, hint: "google" },
  { re: /(?:AKIA|ASIA)[0-9A-Z]{16}/g, hint: "aws_access_key_id" },
  { re: /xox[baprs]-[A-Za-z0-9\-]{10,}/g, hint: "slack" },
  { re: /glpat-[A-Za-z0-9_\-]{20,}/g, hint: "gitlab" },
  { re: /npm_[A-Za-z0-9]{30,}/g, hint: "npm" },
  { re: /pypi-Po-[A-Za-z0-9]{20,}/g, hint: "pypi" },
  { re: /hf_[A-Za-z0-9]{20,}/g, hint: "huggingface" },
];

const JWT_RE = /eyJ[A-Za-z0-9_\-]{5,}\.eyJ[A-Za-z0-9_\-]{5,}\.[A-Za-z0-9_\-]{8,}/g;
const PEM_RE = /-----BEGIN [A-Z0-9 ]*PRIVATE KEY-----[\s\S]*?-----END [A-Z0-9 ]*PRIVATE KEY-----/g;
const KV_RE =
  /([A-Za-z0-9_\-]*(?:token|secret|password|passwd|pwd|api[_-]?key|authorization|access[_-]?key)[A-Za-z0-9_\-]*)["']?\s*[=:]\s*["']?([^\s"'&<>\\]{8,})/gi;

const DENY_RE =
  /^[0-9a-f]{7}$|^[0-9a-f]{40}$|^[0-9a-f]{64}$|^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

function collect(text: string, re: RegExp, confidence: Confidence, hint?: string): Candidate[] {
  const out: Candidate[] = [];
  re.lastIndex = 0;
  let m: RegExpExecArray | null;
  while ((m = re.exec(text))) {
    const value = confidence === "kv" ? (m[2] as string) : (m[0] as string);
    const full = m[0] as string;
    const start = m.index + (full.length - value.length);
    out.push({ value, start, end: start + value.length, confidence, hint: hint ?? m[1] });
  }
  return out;
}

/** Remove candidates swallowed by a longer one, keeping the widest match. */
function dedupe(candidates: Candidate[]): Candidate[] {
  const sorted = [...candidates].sort((a, b) => a.start - b.start || b.end - a.end);
  const kept: Candidate[] = [];
  for (const c of sorted) {
    const last = kept[kept.length - 1];
    if (last && c.start < last.end) {
      if (c.end > last.end) kept[kept.length - 1] = c;
      continue;
    }
    kept.push(c);
  }
  return kept;
}

export function findCandidates(text: string): Candidate[] {
  if (!text.trim()) return [];
  const reserved: Array<{ start: number; end: number }> = findRefs(text).map((r) => ({
    start: r.start,
    end: r.end,
  }));
  const overlaps = (c: Candidate): boolean =>
    reserved.some((r) => c.start < r.end && c.end > r.start);

  const found: Candidate[] = [];
  for (const { re, hint } of ANCHORED) found.push(...collect(text, re, "anchored", hint));
  found.push(...collect(text, JWT_RE, "anchored", "jwt"));
  found.push(...collect(text, PEM_RE, "anchored", "private_key"));
  found.push(...collect(text, KV_RE, "kv"));

  const kept = dedupe(found).filter((c) => !overlaps(c) && !DENY_RE.test(c.value));

  // Bare high-entropy fallback, but never in a context that reads like a hash or URL.
  for (const token of text.split(/[\s,"'()[\]{}<>=;]+/)) {
    if (kept.some((c) => token.includes(c.value))) continue;
    if (DENY_RE.test(token) || /^(?:https?|file|git|ssh|node):/i.test(token)) continue;
    if (token.includes("/")) continue;
    if (!looksCredentialish(token) || shannonEntropy(token) <= 3.9) continue;
    kept.push({ value: token, start: text.indexOf(token), end: text.indexOf(token) + token.length, confidence: "entropy" });
  }
  return kept.sort((a, b) => a.start - b.start);
}

const CONTEXT_WORDS = [
  "github", "gitlab", "anthropic", "openai", "aws", "azure", "gcp", "slack",
  "staging", "prod", "production", "dev", "qa", "deploy", "docker", "npm",
  "pypi", "huggingface", "database", "db", "redis", "vault", "registry", "sandbox",
];

const ALIAS: Record<string, string> = {
  github: "gh", gitlab: "gl", anthropic: "anthropic", openai: "openai", aws: "aws",
  production: "prod", database: "db", huggingface: "hf", access_key_id: "access_key",
};

function slug(s: string): string {
  return s.toLowerCase().replace(/[^a-z0-9]+/g, "_").replace(/^_+|_+$/g, "");
}

export function suggestName(candidate: Candidate, context: string, taken: string[]): string {
  const lower = context.toLowerCase();
  const present = CONTEXT_WORDS.filter((w) => lower.includes(w)).map((w) => ALIAS[w] ?? slug(w));
  const hint = candidate.hint ? ALIAS[candidate.hint] ?? slug(candidate.hint).split("_")[0] ?? "" : "";
  const parts = [hint && !present.some((p) => p.startsWith(hint) || hint.startsWith(p)) ? hint : undefined, ...present.slice(0, 2)].filter(
    (p): p is string => Boolean(p),
  );
  let base = parts.filter(Boolean).join("_").slice(0, 58) || "secret";
  if (!isValidName(base)) base = `s_${base}`.slice(0, 64);
  let name = base;
  for (let n = 2; taken.includes(name); n++) name = `${base}-${n}`.slice(0, 64);
  return name;
}

export function applyCapture(
  text: string,
  candidates: Candidate[],
  nameFor: (c: Candidate) => string,
): { text: string; captured: Array<{ candidate: Candidate; name: string }> } {
  const captured: Array<{ candidate: Candidate; name: string }> = [];
  let out = "";
  let cursor = 0;
  for (const c of [...candidates].sort((a, b) => a.start - b.start)) {
    if (c.start < cursor) continue;
    const name = nameFor(c);
    out += text.slice(cursor, c.start) + `{{sec:${name}}}`;
    cursor = c.end;
    captured.push({ candidate: c, name });
  }
  return { text: out + text.slice(cursor), captured };
}
```

```ts
import type { Vault } from "../vault.ts";
import { findRefs, type Ref } from "../substitute.ts";
import { heredocRegions } from "./bash.ts";

export type RefDisposition = "expand" | "inert" | "unknown";

export interface ClassifiedRef extends Ref {
  disposition: RefDisposition;
}

export function classifyBashRefs(command: string, vault?: Vault): ClassifiedRef[] {
  const regions = heredocRegions(command);
  return findRefs(command).map((ref) => {
    const region = regions.find((r) => ref.start >= r.start && ref.end <= r.end);
    const inert = Boolean(region?.inert);
    const disposition: RefDisposition = inert
      ? "inert"
      : vault && !vault.has(ref.name)
        ? "unknown"
        : "expand";
    return { ...ref, disposition };
  });
}

export function bashRefIssues(command: string, vault: Vault): Array<{ ref: ClassifiedRef; problem: string }> {
  const names = vault.names();
  return classifyBashRefs(command, vault)
    .filter((r) => r.disposition !== "expand")
    .map((r) => ({
      ref: r,
      problem:
        r.disposition === "inert"
          ? `{{sec:${r.name}}} sits in a shell context that will not expand it (quoted heredoc body). Move it outside, or pass it via an environment variable.`
          : `sec:${r.name} not found. Available: ${names.length ? names.map((n) => `sec:${n}`).join(", ") : "(none — run /sec add)"} Values are never shown.`,
    }));
}
```

```ts
import type { Vault } from "./vault.ts";
import { bashRefIssues, expandBash, expandRefs, findRefs } from "./substitute.ts";
import { scrubDeep, scrubText } from "./scrub.ts";
import { applyCapture, findCandidates, suggestName } from "./capture.ts";
import { fingerprint } from "./refs.ts";

const BLOCKED_IN_PATH = new Set(["read", "grep", "find", "ls"]);
const BLOCKED_IN_CONTENT = new Set(["write", "edit"]);

export interface InjectOutcome {
  blocked?: { reason: string };
  expanded: string[];
  env: Record<string, string>;
}

const FILE_WRITE_REASON =
  "sec refs are not written to files (the literal text would be stored, not the value). " +
  "Materializing secrets into files is out of scope. If this value came from a scrubbed " +
  "tool result, tell the user where it needs to go and let them place it.";

function deepFindRefs(value: unknown, hits: Array<{ container: Record<string, unknown> | unknown[]; key: string | number; raw: string; name: string }> = []) {
  if (typeof value === "string") return hits; // leaves are handled by the two callers below
  if (Array.isArray(value)) {
    // Strings inside arrays are leaves too: headers: ["a", "{{sec:x}}"] must expand.
    for (let i = 0; i < value.length; i++) {
      const item = value[i];
      if (typeof item === "string") {
        for (const r of findRefs(item)) hits.push({ container: value, key: i, raw: r.raw, name: r.name });
      } else {
        deepFindRefs(item, hits);
      }
    }
    return hits;
  }
  if (value && typeof value === "object") {
    for (const [k, v] of Object.entries(value)) {
      if (typeof v === "string") {
        for (const r of findRefs(v)) hits.push({ container: value as Record<string, unknown>, key: k, raw: r.raw, name: r.name });
      } else {
        deepFindRefs(v, hits);
      }
    }
  }
  return hits;
}

export function injectBashCommand(command: string, vault: Vault) {
  const issues = bashRefIssues(command, vault);
  if (issues.length) return { command, env: {} as Record<string, string>, expanded: [] as string[], block: { reason: issues[0]!.problem } };
  const out = expandBash(command, (name) => vault.resolve(name));
  return { command: out.command, env: out.env, expanded: out.used };
}

export function injectToolCall(toolName: string, input: Record<string, unknown>, vault: Vault): InjectOutcome {
  const resolve = (name: string) => vault.resolve(name);
  if (BLOCKED_IN_PATH.has(toolName) || BLOCKED_IN_CONTENT.has(toolName)) {
    const serialized = JSON.stringify(input) ?? "";
    if (findRefs(serialized).length) {
      return {
        blocked: {
          reason: BLOCKED_IN_CONTENT.has(toolName)
            ? FILE_WRITE_REASON
            : `sec: refs are not a valid path or pattern for ${toolName}.`,
        },
        expanded: [],
        env: {},
      };
    }
  }
  // bash is owned by the wrapped tool's spawnHook (Task 9). It must see the
  // ORIGINAL ref text — mutating it here would double-expand and drop the env.
  if (toolName === "bash") return { expanded: [], env: {} };
  const refs = deepFindRefs(input);
  if (!refs.length) return { expanded: [], env: {} };
  const expanded: string[] = [];
  for (const hit of refs) {
    const slot = hit.container[hit.key] as string;
    const next = expandRefs(slot, resolve);
    hit.container[hit.key] = next.text;
    for (const n of next.used) if (!expanded.includes(n)) expanded.push(n);
  }
  return { expanded, env: {} };
}

export interface ScrubOutcome {
  content: unknown[];
  details?: unknown;
  hits: number;
}

export function scrubToolResult(
  event: { toolName: string; content: unknown[]; details?: unknown },
  vault: Vault,
  opts: { fileReads: boolean },
): ScrubOutcome {
  const shapes = opts.fileReads || !/^(?:read|grep|find|ls)$/.test(event.toolName);
  try {
    const content = scrubDeep(event.content, vault, { shapes });
    const details = event.details === undefined ? undefined : scrubDeep(event.details, vault, { shapes });
    return {
      content: content.value as unknown[],
      details: details?.value,
      hits: content.hits + (details?.hits ?? 0),
    };
  } catch {
    const masked = event.content.map((block) =>
      block && typeof block === "object" && "text" in block
        ? { ...block, text: "{{sec:redacted}}" }
        : block,
    );
    return { content: masked, details: undefined, hits: 0 };
  }
}

export function scrubMessageText(text: string, vault: Vault, opts: { shapes: boolean }): string {
  try {
    return scrubText(text, vault, opts).text;
  } catch {
    return "{{sec:redacted}}";
  }
}

export function captureFromText(text: string, vault: Vault) {
  const candidates = findCandidates(text);
  if (!candidates.length) return { text, captured: [] as Array<{ name: string; fingerprint: string; length: number; source: "paste" }> };
  const captured: Array<{ name: string; fingerprint: string; length: number; source: "paste" }> = [];
  const taken = vault.names();
  const nameMap = new Map<string, string>();
  const out = applyCapture(text, candidates, (c) => {
    const existing = vault.findByValue(c.value);
    if (existing) return existing.name;
    const name = suggestName(c, text, taken);
    taken.push(name);
    const entry = vault.add(name, c.value, "paste");
    nameMap.set(name, entry.fingerprint);
    captured.push({ name, fingerprint: entry.fingerprint, length: entry.length, source: "paste" });
    return name;
  });
  return { text: out.text, captured };
}
```

```ts
import { createBashToolDefinition, type ExtensionAPI, type ToolDefinition } from "@earendil-works/pi-coding-agent";
import type { Vault } from "../vault.ts";
import { injectBashCommand } from "../glue.ts";

type BashDef = ReturnType<typeof createBashToolDefinition>;

export interface SecureBashOptions {
  vault: () => Vault;
  /** Test seam: observe the expanded command and env before exec. */
  onExpand?: (command: string, env: Record<string, string>) => void;
}

export function createSecureBashToolDefinition(cwd: string, options: SecureBashOptions): BashDef {
  const base = createBashToolDefinition(cwd, {
    spawnHook: (ctx) => ctx,
  }) as BashDef;

  return createBashToolDefinition(cwd, {
    // The hook sees the ORIGINAL command text (refs intact) because tool_call
    // deliberately does not mutate bash input. Spreading env keeps it per-call:
    // parallel bash children never see each other's secrets, and process.env is
    // never touched.
    // Expansion + env only. Output is scrubbed separately in Step 3b, because
    // `tool_result` never fires for a streamed partial.
    spawnHook: (spawnCtx) => {
      const expansion = injectBashCommand(spawnCtx.command, options.vault());
      // Throw rather than exec a literal placeholder; pi surfaces `message` as
      // the tool error the model reads.
      // A non-empty `missing` means at least one ref was NOT substituted, so the
      // command would run with a literal `{{sec:…}}` in it. Never spawn in that case,
      // and keep the two reasons distinguishable: "name not found" is a model error it
      // can fix by listing names, while "we could not determine your quoting" is a
      // lexer limitation the model should not route around by guessing.
      if (expansion.block) throw new Error(expansion.block.reason);
      if (!expansion.expanded.length) return spawnCtx;
      options.onExpand?.(expansion.command, expansion.env);
      return { ...spawnCtx, command: expansion.command, env: { ...spawnCtx.env, ...expansion.env } };
    },
  }) as BashDef;
}

export function registerSecureBash(pi: ExtensionAPI, cwd: string, options: SecureBashOptions): void {
  // createBashToolDefinition already carries promptSnippet, promptGuidelines,
  // renderCall and renderResult, so registering it preserves built-in presentation.
  pi.registerTool(
    withScrubbedUpdates(createSecureBashToolDefinition(cwd, options), options.vault) as unknown as ToolDefinition,
  );
}

/**
 * Did our `bash` actually win?
 *
 * Verified in pi source: extension tools DO replace built-ins (agent-session.js
 * :2128-2133 rebuilds the definition registry from custom tools after the builtins,
 * and :2156-2158 lets extension tools overwrite builtin entries in the tool
 * registry). But among *extensions* the first registration of a name wins
 * (extensions/runner.js:326-334, "first registration per name wins"), so another
 * loaded extension that also registers `bash` can beat us silently.
 *
 * That failure mode is worth detecting explicitly, because it is invisible: refs
 * would then reach the child as literal `{{sec:…}}` text, and pi would report no
 * error at all. Task 10 turns a false result into a loud notify().
 */
export function bashIsOwnedByPiSecure(pi: ExtensionAPI): boolean {
  const effective = pi.getAllTools().find((t) => t.name === "bash");
  return !!effective && effective.sourceInfo.source !== "builtin";
}
```

- [ ] **Step 3b: Scrub the streamed partials (`tool_result` cannot see them)**

Verified in `pi-agent-core/dist/agent-loop.js:459-473`: the built-in bash tool calls
`onUpdate(partialResult)` and pi forwards it as `tool_execution_update` straight to the
renderer. `tool_result` fires only at the end. So a command that echoes a secret —
`printf %s {{sec:gh_pat}}`, or any CLI dumping its own config — prints it on screen
mid-turn even though the final result is masked. Wrap `execute` to intercept `onUpdate`;
the `spawnHook` still owns expansion, so this only observes output.

```ts
import { scrubText } from "../scrub.ts";

export function withScrubbedUpdates<T extends { execute: (id: string, params: unknown, signal: unknown, onUpdate: unknown, ctx: unknown) => unknown }>(
  def: T,
  getVault: () => Vault,
): T {
  return {
    ...def,
    execute: (toolCallId, params, signal, onUpdate, ctx) =>
      def.execute(
        toolCallId,
        params,
        signal,
        typeof onUpdate === "function"
          ? (partial: { content?: Array<{ type: string; text?: string }> }) => {
              const vault = getVault();
              onUpdate({
                ...partial,
                content: partial?.content?.map((block) =>
                  block.type === "text"
                    ? { ...block, text: scrubText(block.text ?? "", vault, { shapes: true }).text }
                    : block,
                ),
              });
            }
          : undefined,
        ctx,
      ),
  } as T;
}
```

`registerSecureBash` composes it: `pi.registerTool(withScrubbedUpdates(definition, options.vault))`.

Add a runtime test — this path is invisible to `tool_result`, so assert on the payload
handed to `onUpdate` while `printf` echoes the secret: it must contain `{{sec:gh_pat}}`
and must not contain the value.

```ts
import type { ExtensionAPI, ExtensionCommandContext } from "@earendil-works/pi-coding-agent";
import { activeVault } from "./vault.ts";
import { isValidName } from "./refs.ts";
import { promptMaskedSecret } from "./masked-input.ts";
import { RECEIPT_TYPE, type Receipt } from "./receipt.ts";
import { setEnabled } from "./state.ts";

const SEC_USAGE = "usage: /sec add|list|remove|rename|test|restore|off|on [name]";

/**
 * Masked entry is the ONLY ingest path that can carry a value: ctx.ui.input()
 * echoes to the terminal, which violates spec §6.1, so never fall back to it.
 */
export async function promptSecret(title: string, ctx: ExtensionCommandContext): Promise<string | undefined> {
  return promptMaskedSecret(ctx, title);
}

export function registerCommands(pi: ExtensionAPI): void {
  pi.registerCommand("sec", {
    description: "Manage this session's secrets: add | list | remove | rename | test | restore | off | on",
    getArgumentCompletions: (prefix: string) => {
      const verbs = ["add ", "list", "remove ", "rename ", "test ", "restore ", "off", "on"];
      const trimmed = prefix.trim();
      const items = verbs
        .map((v) => ({ value: v, label: `/sec ${v.trim()}` }))
        .filter((i) => trimmed.length === 0 || i.value.startsWith(trimmed));
      return items.length ? items : null;
    },
    handler: async (args, ctx) => {
      await runSecCommand((args ?? "").trim(), activeVault(), ctx);
    },
  });
}

export async function runSecCommand(
  input: string,
  vault: ReturnType<typeof activeVault>,
  ctx: ExtensionCommandContext,
): Promise<void> {
  const [verb = "", ...rest] = input.split(/\s+/);
  const arg = rest.join(" ").replace(/^sec:/, "");
  switch (verb) {
    case "": case "help":
      ctx.ui.notify(SEC_USAGE, "info");
      return;

    case "list": {
      const entries = vault.entries();
      ctx.ui.notify(
        entries.length
          ? entries.map((e) => `sec:${e.name} \u00b7 len ${e.length} \u00b7 sha256:${e.fingerprint}`).join("\n")
          : "no secrets in this session",
        "info",
      );
      return;
    }

    case "add": {
      if (!isValidName(arg)) {
        ctx.ui.notify(`invalid name (want /^[a-z][a-z0-9_-]{0,63}$/) \u2014 ${SEC_USAGE}`, "warning");
        return;
      }
      const value = await promptSecret(`Value for sec:${arg} \u2014 paste is fine, it is never echoed`, ctx);
      if (value === undefined) {
        ctx.ui.notify("cancelled \u2014 nothing was stored", "info");
        return;
      }
      try {
        const entry = vault.add(arg, value, "prompt");
        ctx.ui.notify(`captured sec:${entry.name} \u00b7 len ${entry.length} \u00b7 sha256:${entry.fingerprint} \u00b7 this session only`, "info");
      } catch (error) {
        ctx.ui.notify(`not stored: ${error instanceof Error ? error.message : String(error)}`, "error");
      }
      return;
    }

    case "remove": {
      const removed = vault.remove(arg);
      ctx.ui.notify(removed ? `forgot sec:${arg}` : `sec:${arg} was not in the vault`, removed ? "info" : "warning");
      return;
    }

    case "rename": {
      const [from = "", to = ""] = arg.split(/\s+/);
      try {
        // rename() throws on a shell-variable collision but returns false for
        // unknown/invalid/taken, so both channels must be handled here.
        const ok = vault.rename(from.replace(/^sec:/, ""), to.replace(/^sec:/, ""));
        ctx.ui.notify(
          ok ? `sec:${from} is now sec:${to}` : `could not rename sec:${from} (unknown, invalid, or sec:${to} already exists)`,
          ok ? "info" : "warning",
        );
      } catch (error) {
        ctx.ui.notify(error instanceof Error ? error.message : String(error), "warning");
      }
      return;
    }

    case "test": {
      const entry = vault.get(arg);
      // Fingerprint + length only: this is how you confirm a capture without echoing it.
      ctx.ui.notify(
        entry
          ? `sec:${arg} \u00b7 len ${entry.length} \u00b7 sha256:${entry.fingerprint} \u00b7 added ${new Date(entry.addedAt).toISOString()}`
          : `sec:${arg} is not in this session`,
        entry ? "info" : "warning",
      );
      return;
    }

    case "restore": {
      const { restoreSecret } = await import("./restore.ts");
      const { copyToClipboard } = await import("@earendil-works/pi-coding-agent");
      await restoreSecret(arg, vault, {
        copy: copyToClipboard,
        notify: (message, level) => ctx.ui.notify(message, level),
      });
      return;
    }

    case "off":
      setEnabled(false);
      ctx.ui.notify("pi-secure disabled for this session \u2014 refs will not expand", "warning");
      return;

    case "on":
      setEnabled(true);
      ctx.ui.notify("pi-secure enabled", "info");
      return;

    default:
      ctx.ui.notify(`unknown subcommand "${verb}" \u2014 ${SEC_USAGE}`, "warning");
  }
}
```

```ts
import { activeScopeKey, dropSessionVault, setActiveScopeKey, vaultForSession, type Vault } from "./vault.ts";
import { captureFromText, injectToolCall, scrubToolResult } from "./glue.ts";
import { registerSecureBash } from "./tools/bash.ts";
import { createSecListTool } from "./tools/sec-list.ts";
import { expandRefs } from "./substitute.ts";
import { RECEIPT_TYPE, buildReceiptComponent } from "./receipt.ts";
import { isEnabled, setEnabled } from "./state.ts";
import { registerCommands } from "./commands.ts";

export const VERSION = "0.0.1";

function sessionScope(ctx: ExtensionContext): string {
  return ctx.sessionManager.getSessionFile() ?? `ephemeral:${ctx.sessionManager.getSessionId()}`;
}

function vault(ctx: ExtensionContext): Vault {
  return vaultForSession(sessionScope(ctx));
}

export default function piSecure(pi: ExtensionAPI): void {
  pi.on("session_start", async (_event, ctx) => {
    setActiveScopeKey(sessionScope(ctx));
    registerSecureBash(pi, ctx.cwd, { vault: () => vault(ctx) });
    // Silent failure mode worth one line: another extension that registered `bash`
    // first wins among extensions, and then refs reach the child as literal text
    // with no error from pi. Say it out loud, once, per session.
    if (!bashIsOwnedByPiSecure(pi)) {
      ctx.ui.notify("pi-secure: another extension owns `bash`, so {{sec:…}} refs will NOT expand. Load pi-secure after it, or disable that extension.", "error");
    }
    pi.registerTool(createSecListTool(() => vault(ctx)));
    if (ctx.hasUI) ctx.ui.setStatus("pi-secure", "sec: 0 active");
  });

  pi.registerFlag("sec-file-reads", {
    description: "Also mask credential shapes in read/grep output (may break edit round-trips)",
    type: "boolean",
    default: false,
  });

  pi.on("session_shutdown", async (event, ctx) => {
    const reason = (event as { reason?: string }).reason;
    if (reason && reason !== "reload") dropSessionVault(sessionScope(ctx));
    ctx.ui.setStatus("pi-secure", undefined);
  });

  pi.on("input", async (event, ctx) => {
    if (!isEnabled() || event.source === "extension") return { action: "continue" as const };
    const out = captureFromText(event.text, vault(ctx));
    if (!out.captured.length) return { action: "continue" as const };
    pi.appendEntry(RECEIPT_TYPE, { captured: out.captured });
    ctx.ui.notify(
      out.captured.map((c) => `captured sec:${c.name} · len ${c.length} · sha256:${c.fingerprint}`).join("\n"),
      "info",
    );
    ctx.ui.setStatus("pi-secure", `sec: ${vault(ctx).size()} active`);
    return { action: "transform" as const, text: out.text };
  });

  pi.on("tool_call", async (event, ctx) => {
    if (!isEnabled()) return undefined;
    const input = event.input as Record<string, unknown>;
    // For bash this is a no-op: the wrapped tool's spawnHook owns expansion, so
    // the hook must not consume the refs first (see Task 9).
    const out = injectToolCall(event.toolName, input, vault(ctx));
    if (out.blocked) return { block: true, reason: out.blocked.reason };
    return undefined;
  });

  pi.on("tool_result", async (event, ctx) => {
    const fileReads = Boolean(pi.getFlag("sec-file-reads"));
    const out = scrubToolResult(
      { toolName: event.toolName, content: event.content as unknown[], details: event.details },
      vault(ctx),
      { fileReads },
    );
    if (out.hits) {
      // Do not interpolate event.input: it holds expanded args with real values.
      if (ctx.hasUI) ctx.ui.notify(`pi-secure masked ${out.hits} secret occurrence(s) in ${event.toolName} output`, "info");
      // Spec §4: pi writes an UNSCRUBBED snapshot when bash truncates, and hands the
      // model a path to read it from. Rewrite it, or drop it if rewriting fails.
      await scrubOutputSnapshot(out.details, vault(ctx));
    }
    return out.hits ? { content: out.content as never, details: out.details as never } : undefined;
  });

  pi.on("context", async (event, ctx) => {
    if (!isEnabled()) return undefined;
    const v = vault(ctx);
    const messages = event.messages as Array<Record<string, unknown>>;
    const scrubbed = scrubDeepMessages(messages, v);
    return scrubbed.changed ? { messages: scrubbed.messages as never } : undefined;
  });

  pi.on("before_provider_request", (event, ctx) => {
    if (!isEnabled()) return undefined;
    const v = vault(ctx);
    const out = scrubDeepPayload(event.payload, v);
    return out.changed ? out.payload : undefined;
  });

  pi.registerEntryRenderer(RECEIPT_TYPE, (entry, _opts, theme) =>
    buildReceiptComponent(entry.data as { captured: never[] }, theme),
  );

  registerCommands(pi);
}
```

#Helper `scrubOutputSnapshot` lives in `src/glue.ts`:

```ts
import { readFile, rename, unlink, writeFile } from "node:fs/promises";

/**
 * pi's bash truncation writes the FULL raw output to a temp file and prints
 * `Full output: <path>` in the result, so the model can read the unmasked secret
 * straight off disk. Rewrite the file in place; on any failure, delete it and
 * clear the field rather than leave a live path to unscrubbed content.
 */
export async function scrubOutputSnapshot(
  details: unknown,
  vault: Vault,
): Promise<{ cleared: boolean }> {
  const path = (details as { fullOutputPath?: string } | undefined)?.fullOutputPath;
  if (!path) return { cleared: false };
  try {
    const raw = await readFile(path, "utf8");
    const scrubbed = scrubText(raw, vault, { shapes: true });
    if (scrubbed.hits > 0) await writeFile(path, scrubbed.text, "utf8");
    return { cleared: false };
  } catch {
    try {
      await unlink(path);
    } catch {
      /* already gone */
    }
    if (details && typeof details === "object") delete (details as { fullOutputPath?: string }).fullOutputPath;
    return { cleared: true };
  }
}
```

contains the value; then pass a path that cannot be read and assert the field is
cleared. That second branch matters — a stale `Full output:` pointer to content we could

```ts
import type { Vault } from "./vault.ts";

export interface RestoreIo {
  copy(text: string): Promise<void>;
  notify(message: string, level: "info" | "warning" | "error"): void;
  // Deliberately NO editor/setEditor channel: ctx.ui.setEditorText() prefills the
  // input the user submits, which would write the secret into the session
  // transcript. Omitting the parameter makes that leak unrepresentable rather
  // than merely commented against (controller ruling, spec 6.2).
}

/**
 * The escape hatch that makes silent capture safe: the user gets the value back
 * through their own machine — the clipboard — and never through the transcript.
 */
export async function restoreSecret(name: string, vault: Vault, io: RestoreIo): Promise<{ ok: boolean; reason?: string }> {
  const entry = vault.get(name);
  if (!entry) return { ok: false, reason: `sec:${name} is not in this session` };
  try {
    await io.copy(entry.value);
  } catch (error) {
    const reason = `clipboard unavailable (${error instanceof Error ? error.message : "unknown"}) — nothing was revealed`;
    io.notify(`could not restore sec:${name} to the clipboard`, "error");
    return { ok: false, reason };
  }
  io.notify(`sec:${name} is on your clipboard · len ${entry.length} · sha256:${entry.fingerprint}`, "info");
  io.notify("the value was not placed in the editor — typing it there would persist it", "warning");
  return { ok: true };
}
```

```ts
  faux.setResponses(options.responses);
  const runtime = await ModelRuntime.create({ allowModelNetwork: false, refreshOnCreate: false });
  // ModelRuntime.registerProvider takes (id, config), NOT a Provider object, so
  // the faux Provider is registered through the extension API (which does accept
  // a full pi-ai Provider) via a named inline factory below.

  const cwd = options.cwd ?? mkdtempSync(join(tmpdir(), "pi-secure-cwd-"));
  // An explicit sessionDir keeps every artifact inside a temp dir the sweep can
  // scan; the default resolves under the real ~/.pi/agent/sessions.
  const sessionDir = mkdtempSync(join(tmpdir(), "pi-secure-sessions-"));
  const loader = new DefaultResourceLoader({
    cwd,
    extensionFactories: [
      { name: "pi-secure-faux-provider", factory: (pi) => pi.registerProvider(faux.provider) },
      { name: "pi-secure", factory: piSecure },
    ],
  });
  await loader.reload();
  const sessionManager = SessionManager.create(cwd, sessionDir);
  const { session } = await createAgentSession({
    cwd,
    model,
    modelRuntime: runtime,
    sessionManager,
    resourceLoader: loader,
    tools: options.tools ?? ["bash", "read", "write", "edit"],
  });
  return {
    session,
    faux,
    cwd,
    sessionDir,
    model,
    sessionFile: () => session.sessionFile,
    dispose: () => session.dispose(),
  };
}

/** Every session and temp file this run may have written. */
export function artifacts(sessionDir: string): string[] {
  const files: string[] = [];
  const walk = (dir: string, depth = 0) => {
    if (depth > 6) return;
    for (const entry of readdirSync(dir, { withFileTypes: true })) {
      const full = join(dir, entry.name);
      if (entry.isDirectory()) walk(full, depth + 1);
      else files.push(full);
    }
  };
  try {
    walk(sessionDir);
  } catch {
    /* no session dir yet */
  }
  // pi's bash truncation writes raw snapshots here — spec §4 row 7.
  for (const entry of safeReaddir(tmpdir())) {
    if (entry.startsWith("pi-bash")) files.push(join(tmpdir(), entry));
  }
  return files;
}

function safeReaddir(dir: string): string[] {
  try {
    return readdirSync(dir);
  } catch {
    return [];
  }
}

export function readAll(files: string[]): string {
  return files.map((f) => readFileSync(f, "utf8")).join("\n");
}
```

```ts
import type { ExtensionCommandContext } from "@earendil-works/pi-coding-agent";

export interface MaskState {
  buf: string;
  cursor: number;
  status: "editing" | "submit" | "cancel";
}

export function emptyMaskState(): MaskState {
  return { buf: "", cursor: 0, status: "editing" };
}

const PASTE_ON = "\x1b[200~";
const PASTE_OFF = "\x1b[201~";

function stripFraming(data: string): string {
  return data.replaceAll(PASTE_ON, "").replaceAll(PASTE_OFF, "");
}

export function applyInput(state: MaskState, data: string): MaskState {
  if (state.status !== "editing") return state;
  let buf = state.buf;

  // Escape alone (not the lead byte of a CSI sequence) cancels.
  if (data === "\x1b") return { buf: "", cursor: 0, status: "cancel" };
  if (data === "\x03") return { buf: "", cursor: 0, status: "cancel" };

  const cleaned = stripFraming(data);
  const newline = /[\r\n]/.exec(cleaned);
  const head = newline ? cleaned.slice(0, newline.index) : cleaned;

  for (const ch of head) {
    if (ch === "\x7f" || ch === "\b") buf = buf.slice(0, -1);
    else if (ch === "\x1b") return { buf: "", cursor: 0, status: "cancel" };
    else if (ch.codePointAt(0)! >= 32) buf += ch;
  }

  if (newline) {
    const tail = cleaned.slice(newline.index).replace(/[\r\n]/g, "");
    buf += tail;
    return { buf, cursor: buf.length, status: "submit" };
  }
  return { buf, cursor: buf.length, status: "editing" };
}

/** Deliberately ignores the value: renders `•` × length plus a live length. */
export function renderMasked(state: MaskState, title: string, width: number): string[] {
  const dots = "•".repeat(state.buf.length);
  const clipped = dots.length > Math.max(0, width - 12) ? dots.slice(-Math.max(0, width - 12)) : dots;
  return [
    title.slice(0, width),
    clipped || " ".repeat(1),
    `len ${state.buf.length} · enter to store · esc to cancel`.slice(0, width),
  ];
}

export async function promptMaskedSecret(
  ctx: ExtensionCommandContext,
  title: string,
): Promise<string | undefined> {
  if (ctx.mode !== "tui" || !ctx.hasUI) return undefined;
  const result = await ctx.ui.custom<{ value?: string }>((_tui, theme, _kb, done) => {
    let state = emptyMaskState();
    let dirty = true;
    const finish = () => {
      if (state.status === "submit") done({ value: state.buf });
      else done({});
      state = { buf: "", cursor: 0, status: state.status }; // drop the buffer ASAP
    };
    return {
      render(width: number) {
        const lines = renderMasked(state, title, width);
        return lines.map((l, i) => (i === 1 ? theme.fg("toolTitle", l) : theme.fg("muted", l)));
      },
      invalidate() {
        dirty = true;
      },
      handleInput(data: string) {
        const previous = state.status;
        state = applyInput(state, data);
        dirty = true;
        if (state.status !== previous) finish();
      },
      dispose() {
        state = { buf: "", cursor: 0, status: "cancel" };
      },
    };
  });
  const value = result?.value;
  return value && value.trim() ? value : undefined;
}
```

### Task 16: Truncation-aware masking of encoded secrets

**Why.** `maskForms` requires the **whole** form to appear: `search.indexOf(form)`. When tool output
is truncated, an encoded vaulted secret can be present only as a *fragment*, and a fragment scores
zero hits. Measured: a 64-byte secret base64-encodes to 88 characters; wrapped at 64 columns and
cut at 84 characters, **94% of the encoding is visible and nothing is masked** — roughly 62 of the
64 secret bytes, whose remaining 2 are brute-forceable and verifiable against the visible prefix.
The direction matters and it is the opposite of the obvious guess: pi's bash tool truncates **to the
last** 5000 lines or 50KB and can return a *partial last line* (`dist/core/tools/bash.js`,
`truncate.js`), so in practice the surviving fragment is the **tail** of the encoding, not the head.
Head fragments arrive from `head`, pagers, and streamed partials. A fix that registers only a head
window would be dead code against pi's own truncation.

**Files:** Modify `src/scrub.ts` (`collectForms`, `maskForms`); extend `test/scrub.test.ts`.

**Design — windows plus maximal-run extension, not more whole forms.**

1. For each **encoding** form of length ≥ 40, register a fixed-size window at its head and at its
   tail (≥ 24 characters). Two windows per encoding, not one per possible cut point.
2. When a window matches, do not mask only the window: extend the replaced span outward over the
   encoding's alphabet, whitespace-tolerantly via the existing shared stripped buffer, so the
   entire visible run is masked whatever the cut point. A run stops at a character that cannot
   belong to the encoding.
3. **Never** window raw values — that is requirement 12's prose-mangling class — and never window an
   encoding shorter than 40 characters. An 8-character vault entry produces the base64 prefix
   `YWJjZGVm`, which is already plausible inside ordinary text; that case is covered by the existing
   whole-form match and must not gain a window.

**Acceptance.** Existing 125 tests stay green. New tests, written first and shown RED against the
shipped module: tail-truncated wrapped base64 (pi's actual case), head-truncated, a mid-line cut at
a non-4-aligned offset, and the negative — an 8-character secret whose base64 prefix appears inside
prose must stay untouched. Re-measure the performance guard after the extra forms: the current
1.07MB / 16-entry scrub is 33ms and windows add two `indexOf` passes per encoding, so stay in that
order or explain the drift.

**Stop rule.** If maximal-run extension cannot be bounded tightly enough to pass the negative test
without masking adjacent non-secret text, stop and document the residual in spec §12 rather than
shipping an over-masking matcher: destroying the tail of every large `git diff` would make the
extension unreadable, and unreadable output is how users end up pasting tokens by hand.

**Also record as limits, not work:** a secret split across two separate tool results needs session
state and is out of scope; UTF-16 or NUL-interleaved bytes defeat every byte-oriented form;
percent-encoded secrets are unaffected when the token is alphanumeric, and outside reach otherwise.

### Task 15: Single-pass bash lexical scanner (replaces the mutually-recursive pair)

**Why this task exists.** Task 4 fixed five defects in four rounds and every one traced to
the same structure: `quoteIntervals` needs heredoc regions to track quotes, `heredocRegions`
needs quote intervals to find operators, and neither reports comments — which both need. Each
patch threaded one ordering (left-to-right, regions-so-far) and left a shape it could not
see. This is a hardening task, not a security fix: the surviving defects make commands fail
or receive a literal variable name, and the value stays inside the child environment either
way. It must land **before Task 7 and Task 9**, which are the two consumers of lexical
context, so neither is written against an API about to be replaced.

**Files:**
- Modify: `src/substitute/bash.ts` (scanner internals), `src/substitute.ts` (re-export surface)
- Test: extend `test/bash-expansion.test.ts`, `test/bash-heredoc-edges.test.ts`; keep `test/bash-quote-table.ts` as a fixture contract

**Interfaces:**
- Produces: `scanBash(text: string): BashLex` where
  `interface BashLex { spans: { kind: SpanKind; start: number; end: number }[]; unterminated: { kind: SpanKind; index: number } | null }`
  and `type SpanKind = "sq" | "dq" | "ansq" | "loc" | "comment" | "heredoc" | "arith"`.
  `expandBash` consumes `BashLex`; the context of an index is a single lookup.
- `quoteIntervals` and `heredocRegions` may be deleted, but `heredocRegions` is imported by
  `test/bash-heredoc-edges.test.ts` through `src/substitute.ts` — either keep a thin
  compatible wrapper over `scanBash` or update that test's imports. Decide before writing code.

**Requirements — each of these is a measured bash fact, and each is currently wrong or held
together by an ordering accident:**

1. **One pass, explicit stack.** No scanner may need the other's output. Context is decided
   as it is discovered, so the per-operator recomputation in `heredocRegions` disappears.
2. **Delimiters are any unquoted word.** `cat <<1`, `cat <<E-O-F` and `cat <<EOF.txt` all run
   in bash (measured: they print their bodies); the current `[A-Za-z_][A-Za-z0-9_]*` rejects
   them, so those bodies are never excluded — with an even apostrophe count that is the silent
   splice again (`<<1` + `&& echo 'x'` measured producing it). Widen to a non-word character
   class such as `[^\s|&<>();]+`, and note that requirement 3 must land **with** it: the
   narrow charset is currently the only thing stopping `$((m<<k))` from matching.
3. **Arithmetic is its own context.** `echo $((1<<2))` must not be read as a heredoc
   operator. A `wordStart` test excludes it (digits clear the flag); `#` needs the same test,
   so a comment-start check and an arithmetic guard are one mechanism, not two.
4. **Operators inside comments are text.** `# cat <<EOF` makes the rest of that line a comment
   in bash (measured: it runs line 2 as a command and prints `done`), so an operator found
   there registers nothing. This requires the scanner to report comment spans, which the
   current pair cannot.
5. **Keep everything Task 4 already pinned**, unchanged, as the acceptance harness: all
   `<<-` tab semantics (tabs stripped, spaces not), `<<-'EOF'`, `<<<` here-strings, two
   operators on one line, body lines that merely start with the delimiter, `<<EOF>>` and
   `<<EOF 2>&1`, unterminated heredoc to EOF, operator inside a real quote, the `(cd .)#don't`
   and `\;#` cases, and refs inside inert bodies blocking while refs in expanding bodies use
   `${VAR}`.
6. **Plumb `unterminated` through.** The destructure at the head of `heredocRegions` drops it
   today; a caller must be able to distinguish "quote never closed in code context" from
   "everything balanced".

**Verification.** `npx vitest run` and `npx tsc --noEmit` clean; the Task 4 corpus green
without editing any assertion (except import lines if `heredocRegions` is retired); then write
the four cases above as new tests first and see them fail against `src/substitute/bash.ts` as
it stands before this task starts. If any is already green, say so rather than claiming a fix.

**Also owed by this task, carried from Task 4's round 5 as disclosed gaps:**

- **Pin the redirection boundaries with tests, not reasoning.** `>` joined the set in round 5
  with no direct case; the measured facts are that `: >#f`, `echo hi >#log`, `: <#f`,
  `echo hi <#f` and `echo x <<<#f` all exit 2 and create no file. Add one test per boundary
  (`x>#f`, `x<#f`, `x<<<#f`) asserting the ref after it is treated as comment text, so the
  normalization is a contract rather than a trace-through argument.
- **The per-operator rescan is quadratic** in the number of operators, because each one
  re-runs `quoteIntervals` over the whole text. Harmless at command size, but the single-pass
  design removes it; do not "optimize" the pair instead of replacing it.

**Also owed here, from Task 4's closing review:**

- **`\<newline>` is not the same as `\<char>`.** Bash deletes both characters and continues in
  the *same* parser state, so a line continuation must leave `wordStart` alone, while a normal
  escape pair must clear it. Measured: `echo x ` + `\` + newline + `#don't` comments (prints
  `x`, identical to `echo x #don't`), but the blanket clear added by Task 4's requirement 7
  misses that comment and splices into text bash discards. Observable class: already-deferred
  "a ref inside a comment is inert yet reported used" — a new door, not a new class.
- **Two different `)` must be distinguished.** `(cd .)#c` comments (`)` closes a *subshell*, so
  a new word begins) while `y=$(printf a)#c` does not (`)` closes a command substitution *inside*
  a word that began at `y`) — both measured against bash. The current set treats them alike and
  requirement 7's clear happens to mask the error whenever an escape intervenes. Only a context
  stack fixes it properly; that is the strongest single argument for this task.
- **Restore the `heredocBodies.length > 0` short-circuit** (or replace the scan with a sorted
  cursor). Requirement 6's `find()` allocates a closure per code-state character even with no
  heredocs present.
- **Two test comments cite the wrong string.** The one at the escape test quotes
  `echo y=a;#bc q d`, which is not that test's `src`, and the regex in the same test has a
  duplicated character class (`[^""]*` for `[^"]*`). Comments are the durable spec here; make
  them match the code they describe.

**Stop rule.** If the rewrite cannot close requirement 2 and 4 together within one pass,
stop and report which shapes remain — a documented limit in spec §12 is a better outcome than
a sixth reconstruction of the same idea.
